## 개요

- **장르**: 2.5D 로그라이트 RPG (아래로 내려가는 플랫폼 액션 형식)
- **플랫폼/인원**: 1인용
- **성장 시스템**: 던전에서 획득한 자원으로 마을이나 기지에서 캐릭터 능력치를 영구적으로 성장시키는 방식
  - 다른 게임과 유사해질 위험(차별화 부족) 있음 → 재고 필요

## 던전 구조

- 아래로 계속해서 내려가는 종스크롤/플랫폼 형태 (예: 스펠렁키, 다운웰 등)
- **구간별 테마 시스템**: 특정 층수마다 배경, 몬스터, 함정의 콘셉트가 완전히 바뀜
  - 예: 1~5층 지하 감옥, 6~10층 버려진 광산 등
- **보스전**: 각 테마(구간)의 마지막 층에 강력한 보스 등장, 처치해야 다음 테마로 진행
- **클리어 보상**: 스펙업(능력치 up / 스킬 해금) 카드 3개 중 선택하는 구조

## 세계관

- **배경**: 다크 판타지 (던전)
- **세계관**: 멸망한 중세시대. 던전이 생겨나고, 던전에서 나오는 부산물로 생계를 이어감
  → 던전 중심 경제/마을 형성 → 탐험가들은 던전을 돌며 재화를 수급하며 생활
  → 신적 존재(선/악), 광신도 등 여러 문제 발생
  → 길드가 탐험가에게 마을을 지키기 위한 퀘스트 부여
  → 길드는 게임 플레이 중 얻은 재화로 캐릭터를 강화하는 장소
  → **목표**: 던전의 최심부까지 도달하는 것

## 핵심 시스템

- **무기 선택** (시작 시): 검, 활, 단검, 지팡이, 방패 등 (변동 가능)
  - 컨셉: 신들은 과거 탐험가였고, 탐험가 시절 사용하던 장비를 좋아함
    - 예: 검을 사용하는 신은 검 사용자를 좋아함
  - 신의 은총을 과도하게 받으면 **잠식 게이지**가 상승 → 100% 도달 시 게임 종료(또는 디버프, 회의 내용 참고)
- **부가 시스템**: 신들 간 우호도, 유물 시스템(디버프 완화 or 버프 증폭), 유물 간 시너지
- **엔딩**: (미정, 메모상 "ANG KIMOCCHI")

## 개발 구상안 — 회의록

### 06.26 1차 회의

- 던전 1스테이지 클리어 시 카드 획득 → 스펙업(능력치 증가 / 스킬 해금)
- 직업이 아닌 **무기 중심**으로 설계 방향 전환
  - Tree 형식의 스킬 마스터리 체계 지향
- **광신도 테마**
  - 스테이지 클리어 시 등가교환 방식으로 레벨업
  - 성향 시스템(검의 성좌, 활의 성좌 등)으로 확장
  - 몬스터에게서 얻은 재화를 광신도에게 바쳐 축복을 받는 구조
  - 보스 후보: 레전드 사이비 / 광신도 무리
  - 저주 회수 방법: 재화로 디버프 해제 선택지 제공

### 06.27 2차 회의

- **무기 중심 설계 확정**: 주인공 한 명 + 무기 교체 방식
  - 무기: 검, 활, 지팡이 (초기 3종, 추후 확장)
- **출신(배경) 시스템** 추가 — 출신 + 무기(주무기/보조무기) 조합
  - 기본: 노숙자 (효과 없음)
  - 몰락귀족: 재화 획득량 증가
  - 방랑기사: 검 계열 무기 사용 시 버프
  - 사제: 경험치 획득량 증가 or 지팡이 계열 무기 사용 시 버프
  - 농부: 체력 증가
  - 악마사냥꾼: 아무 효과 없음, 선택 불가(최고 난이도 전용)
- 스탯이 아닌 **무기 자체의 강화**로 성장
- 자동 공격 없음 (직접 조작)
- **잠식 게이지**
  - 카드 선택 시 이득 정도에 따라 게이지 상승, 100% 초과 시 0%로 리셋되며 디버프 부여
  - 디버프는 사전 정의된 목록에서 랜덤 적용 (중첩 가능)
  - 디버프 목록: 최대체력 감소, 받는 피해 증가, 공격속도 감소, 데미지 감소, 이동속도 감소
- **구성 요소**: 출신, 시작무기, 무기, 아이템, 은총, 제단
  - 아이템: 디버프 1회 무시 아이템 등
  - 재화: 영혼(신과 거래), 골드(상점 구매/강화)
  - 악마의 성향에 따라 은총 선택 가능
- **층 구성**
  - 안전지대(층 하나 차지): 아이템 상점, 대장장이(무기 강화)
  - 제단: 악마를 불러 영혼 대가로 힘을 얻음
  - 한 층 구성: 상점(아이템/대장장이) + 제단(은총) + 보스(층 클리어 시) + 광신도방 + 보상방(피난처 NPC 상호작용, 낮은 확률로 보상 상자가 미믹으로 변이)
  - 맵은 층마다 랜덤 배치
  - **5층마다 보스** 등장
  - 1~4층 클리어 조건: 광신도방을 깨거나 무시하고 통과
    - 광신도방 클리어 시: 5층 보스가 약화(디버프)
    - 무시 시: 5층 보스는 초기 상태로 등장
- **아이템**
  - 장착용: 부적(1회용), 장비
  - 드랍 아이템은 사용 or 골드로 환전 선택
- **UI 레이아웃**
  - 인벤토리 없음(대신 분해 기능)
  - 좌상단: 미니맵 아래 재화 표시
  - 우상단: 잠식 게이지, 부적 소지 여부
  - 좌하단: 스킬 목록
  - 우하단: 장비 목록 5칸 (주무기, 보조무기, 장신구1, 장신구2, 소모품 — 5번 키로 포션 등 소모품 전환)
  - 중앙 하단: 체력, 기력, 마나
  - 중앙 상단: 보스 체력바
